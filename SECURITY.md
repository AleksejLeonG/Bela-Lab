# Security

Use the latest published Bela Lab version when reporting a security issue. Bela Lab 1.0.0 is the current release version.

Use [GitHub Security Advisories](https://github.com/AleksejLeonG/Belote_engine/security/advisories) if the **Report a vulnerability** button is available. Otherwise, open a [GitHub issue](https://github.com/AleksejLeonG/Belote_engine/issues) asking for a private contact channel without including sensitive details.

Include your app version, Windows version, a short description, and the minimum information necessary for the maintainer to understand the issue. Remove personal information, saved matches and confidential details from public posts.
