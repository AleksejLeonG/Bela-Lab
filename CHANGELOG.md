# Changelog

## 1.0.0

- Windows desktop app with bot play, manual tracking, saved matches and match export.
- Review board with alternate plays, saved analysis and a game coach.
- Monte Carlo move advice, exact search for small endgames, and match-aware ranking near the finish.
- Opening lead comparisons with expected deal points, contract odds and first-trick odds.
- English and Croatian interface, light and dark themes, and Hungarian and standard card faces.
- Versioned Windows distribution with privacy, terms, support and third-party notices.
- Windows Setup wizard with a Start menu shortcut and an uninstall entry that keeps saved games and settings.
